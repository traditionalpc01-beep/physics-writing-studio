# Results Section — Nature Standard

Goal: present findings as a story, with each subsection a self-contained claim supported by figures. Subsections usually have **bolded titles** that summarize the claim (`**X drives Y by Z**`).

## Per-subsection architecture

1. **Lead sentence (topic):** state the finding.
   - Template: `We find that X ... (Fig. 1a).` or `To investigate X, we ...`
   - Physics example: `We find that devices with the passivated NiOx layer exhibit an EQE of 21.3% (Fig. 1a).`
2. **Evidence paragraph:** describe the data, with figure anchors.
   - `The luminance was 1.8-fold higher than in the control devices (average ± s.d. over N devices; Fig. 1a).`
   - `The EQE showed a 2.1-fold increase relative to the reference stack (Fig. 1b).`
3. **Controls / replication:** rule out alternative explanations.
   - `To rule out substrate effects, we fabricated reference devices without the SAM interlayer.`
   - `This observation was reproduced in an independent fabrication batch (n = N devices).`
4. **Transition to next:** set up the next claim.
   - `Having established X, we next asked whether Y.`

## Multi-subsection flow

- 3-5 themed subsections, each ~3-5 paragraphs.
- Each subsection's title is a 1-line claim, not a generic label.
  - GOOD: `**Hole-hole correlations beyond nearest neighbours**`
  - BAD: `**Results Part 1**`
- Build: each subsection depends on previous, ascending complexity.
  - P1: descriptive (`We characterize X.`)
  - P2: mechanistic (`We show X drives Y by Z.`)
  - P3: operating-condition / lifetime (`X is required for Y under continuous driving.`)
  - P4: implications (`These findings suggest ...`)

## Hard rules

- Every non-trivial claim must have a figure/data anchor.
- Numerals for 10+; spell out 1-9.
- Statistics inline: `(P < 0.001, two-sided t-test)` not just `(P < 0.001)`.
- Specify n for each experiment.
- No figure numbers like "Figure 1" — always "Fig. 1".
- No "as shown in the figure below" — figure anchors are parenthetical only.
- Use past tense (`We found`, `We measured`, NOT `We find`, `We measure`).

## Quantitative writing

| Pattern | Example |
|---|---|
| Fold change | `The passivated devices showed a 2.4-fold increase in lifetime relative to controls (average ± s.d. over 30 devices).` |
| Proportion | `The EQE exceeded 20% in 24 of 30 devices (80%).` |
| Correlation | `EQE correlated inversely with leakage current (r = −0.82, N = 30 devices).` |
| Effect size | `The interlayer reduced the leakage current by 47% (95% CI 32–58%).` |
| Device statistics | `average ± s.d. over N devices; state N and define error bars in the legend (exact P values are uncommon in device physics)` |

## Anti-patterns in Results

- `Interestingly, ...` (overused; remove unless truly striking)
- `Surprisingly, we found ...` (subjective; show via data)
- `As expected, ...` (vague; state what was expected)
- `Notably, ...` (use sparingly; once per section max)
- Repeating abstract findings verbatim — paraphrase in fresh language
- Long methods recap inside Results — refer to Methods section
