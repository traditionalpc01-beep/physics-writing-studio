# Nature Style Guide — distilled from 750 Nature Portfolio papers

## Hedge Tiers (use one per claim)

| Tier | Verbs / Modals | Use when |
|---|---|---|
| **Causal** | `we demonstrate / show / identify / establish / report that` | Author's own data with controlled comparison |
| **Associative** | `consistent with / in line with / supports / suggests / our data are consistent with` | Correlative data without controlled comparison |
| **Speculative** | `may / could / might / appears to / one possibility is` | Proposed mechanism, hypothesis, indirect evidence |

## Sentence Templates (per section)

### Abstract (≤ 200 words, often ≤ 150)
- Background: `Quantum-dot light-emitting diodes (QLEDs) are an emissive display technology that combines narrow-linewidth emission with solution processing.`
- Gap: `However, blue QLEDs remain limited by the efficiency–stability trade-off.`
- Method: `Here, by spin-coating a passivated NiOx hole-injection layer, we improve hole injection and operational stability.`
- Lead finding: `We find that devices reach an EQE of 21.3% and a luminance of 30,000 cd m⁻² (Fig. X).`
- Integrative: `Together, our findings reveal that interfacial passivation governs the efficiency–stability trade-off.`
- Closing: `Our study provides a design principle for stable hole-injection layers in QLEDs.`

### Introduction
- P1 broad: `Colloidal quantum dots are the emitter class that enables narrow-linewidth displays. ... Charge imbalance has been implicated in efficiency roll-off1,2.`
- P2 background: `Previous studies have shown that NiOx hole-injection layers improve hole extraction in inverted device stacks1,2,3.`
- P3 gap: `Despite these advances, the mechanism of hole-injection degradation at the NiOx/QD interface remains elusive.`
- P4 aim: `Here we developed a passivated NiOx hole-injection layer to enable stable blue QLEDs. ... We find that ...`

### Results
- Lead: `We find that devices with the passivated layer exhibit an EQE of 21.3% (Fig. 1a).`
- Quant: `The luminance was 1.8-fold higher than in the control devices (average ± s.d. over N devices).`
- Control: `To rule out substrate effects, we fabricated reference devices without the passivated interlayer.`
- Transition: `Having established improved hole injection, we next asked whether it extends device lifetime.`

### Methods (past passive)
- `Devices were fabricated on ITO-coated glass substrates inside a nitrogen glovebox.`
- `The NiOx layer was spin-coated at 3,000 r.p.m. for 40 s and annealed at 150 °C for 20 min in air.`
- `J–V–L characteristics were measured using a calibrated silicon photodiode.`

### Discussion
- P1 restate: `Our data suggest that the passivated NiOx layer suppresses interfacial non-radiative recombination.`
- P2 mechanism: `Mechanistically, the EQE gain is attributed to balanced charge injection.`
- P3 limit: `We note that our analysis is limited to blue-emitting devices.`
- P4 outlook: `It will be important to test this hole-injection layer in top-emitting device architectures.`

### Figure Caption
- `Fig. N | Title-Case Statement of What Is Shown.`
- `a, Description of panel a. b, Description of panel b.`
- Stats: `n = N devices; average ± s.d.`
- Scale: `Scale bar, X nm.`

## Numerals

- Spell out 1-9 in running text (`three device batches`).
- Numerals for 10+ (`152 devices`, `44 pixels`).
- Always numerals in statistics, units, figure callouts.
- Percent: `52%` (no space). Temperature: `5 °C` (with space).

## Citations

- Numeric superscript: `QLEDs3–8` (Nature style).
- Group consecutive: `1–5`. Non-consecutive: `1,3,5`.
- Cite immediately after concept, not at sentence end.

## Cross-section hedge ladder (multi-section writing only)

When `target=multi_section`, hedge tier must soften (or stay equal) as the section index advances. The canonical ladder from `knowledge/cross_section_rules.tsv` (X001):

| section | tier | example verb / modal |
|---|---|---|
| abstract (lead finding) | causal | `We find / show / identify / demonstrate that X.` |
| introduction (P1-P2, prior work) | associative | `X has been implicated in Y; consistent with Z.` |
| introduction (P4, own approach preview) | causal | `We developed X to enable Y.` |
| results (own data) | causal | `We find / show / demonstrate that X.` |
| discussion (mechanism) | associative | `This is consistent with the notion that X.` |
| discussion (outlook) | speculative | `X may / could contribute to Y.` |

Hedge can stay equal across adjacent sections (results causal -> discussion associative is a *softening*; results causal -> introduction causal is forbidden because introduction precedes results). Never strengthen backward (X001). Same underlying claim must carry the same tier across abstract / intro / results / discussion (X007).

## Cross-section entity continuity (multi-section writing only)

Every number, abbreviation, material, layer thickness, device structure, and named device/material entity in the input draft must be registered up front in `entity_registry` and then appear byte-identically in every section that mentions it (X002). Abbreviation expansions (X004):

- First occurrence in the entire paper = full term + parenthetical abbreviation.
- Later occurrences = abbreviation only.
- Same expansion placement decision across all sections.

Citation numbering (X003):

- Numeric superscripts assigned in order of first mention in the whole paper, not per-section.
- Never reuse a number; never skip a number.
- Citation density (X010): intro 5-10/section, results 0-2 (own data), discussion 1/paragraph.
